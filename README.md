
# Vision

A native iOS companion app for managing media requests on your self-hosted Overseerr, Jellyseerr, or Seerr server.

## Features

- Connect to any Overseerr, Jellyseerr, or Seerr server
- Search for movies and TV shows
- Submit and manage media requests
- View request status in real time
- Secure connection to your own self-hosted server

## Requirements

- iOS 16.0 or later
- A running instance of Overseerr, Jellyseerr, or Seerr

## Getting Started

1. Download Vision from the App Store
2. Open the app and enter your server URL (e.g. `https://overseerr.yourdomain.com`)
3. Sign in with your Overseerr/Jellyseerr/Seerr credentials
4. Start browsing and requesting media

## Support

Having an issue or have a question? Reach out to us at **support@dontevenpeek.com** or [open an issue on GitHub](https://github.com/xcrailer/Vision/issues) and include:

- Your server type (Overseerr / Jellyseerr / Seerr)
- Your server version
- Your iOS version
- A description of the problem

## Privacy Policy

Vision does not collect, store, or share any personal data. All communication happens directly between your device and your own self-hosted server. No analytics or tracking of any kind is used.
